# Venus

Application PHP de navigation et d'administration des rubriques CRAc-RF.

## Configuration locale

1. Copier `config/config.example.php` vers `config/config.php`.
2. Adapter les constantes `DB_HOST`, `DB_NAME`, `DB_USER` et `DB_PASS`.
3. Importer le schéma ou les migrations depuis `init_db/`.

Le fichier `config/config.php` contient les identifiants locaux et n'est pas versionné.
